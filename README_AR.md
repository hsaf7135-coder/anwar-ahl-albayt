# أنوار أهل البيت — نسخة البداية 0.2

مشروع Flutter أولي باللغة العربية. الواجهة الرئيسية والأقسام وصفحات المحفوظات والإعدادات تعمل محلياً، لكن محتوى الأقسام ما زال تجريبياً.

## التطوير من الهاتف فقط

1. نزّل ملف ZIP إلى هاتفك وافك ضغطه باستخدام مدير الملفات.
2. افتح حساب GitHub إذا لم يكن لديك حساب، وأنشئ مستودعاً جديداً خاصاً للمشروع.
3. ارفع محتويات المجلد إلى المستودع. الأسهل عادةً فتح GitHub في متصفح الهاتف وتفعيل عرض سطح المكتب.
4. افتح بيئة سحابية تدعم Flutter وAndroid SDK، ثم افتح المستودع داخلها.
5. في الطرفية نفّذ:
   ```bash
   flutter doctor
   flutter pub get
   flutter analyze
   flutter build apk --release
   ```
6. إذا نجح البناء، نزّل APK من مسار:
   `build/app/outputs/flutter-apk/app-release.apk`

مهم: ليست كل البيئات السحابية تحتوي Android SDK. إذا ظهر خطأ يفيد أن Android SDK أو Flutter غير موجود، فاختر بيئة معدّة مسبقاً لدعم Flutter Android.

## ما يعمل في هذه النسخة
- واجهة عربية باتجاه RTL.
- ستة أقسام رئيسية.
- صفحات للأقسام.
- إضافة وإزالة عناصر من قائمة المحفوظات أثناء تشغيل التطبيق.
- صفحة إعدادات أولية.

## ما يزال مطلوباً
- حفظ المفضلة بين مرات تشغيل التطبيق.
- إدخال نصوص القرآن والأدعية والزيارات من مصادر موثوقة ومراجعتها.
- مواقيت الصلاة والقبلة باستخدام موقع المستخدم وإعدادات الحساب.
- تشغيل الصوتيات، إدارة الملفات والحقوق.
- اختبار فعلي على أندرويد وإعداد التوقيع والنشر.

## ملاحظة حول المحتوى
العناوين الموجودة أمثلة توضيحية وليست نصوصاً دينية كاملة. لا تنشر المحتوى قبل مراجعة مصادره وحقوق استخدامه.
